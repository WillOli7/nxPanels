**nxPanels** adds artistic panels to your interface: backgrounds, borders, text and scripts, placed anywhere and attached to any frame.

> **Coming from kgPanels Reloaded?** Same project, new name. **Nothing to do:** your layouts are imported on the first start, and your old data is never modified.

> Problem or question? Comments or [GitHub](https://github.com/WillOli7/nxPanels/issues).

## Features
- **Configuration window** (`/nxp`) and **edit mode** (`/nxp edit`): move and resize with the mouse, snapping, alignment guides, undo.
- **Backgrounds and borders:** your textures, SharedMedia, Blizzard images, chosen in a thumbnail browser. Automatic class, faction or target colors.
- **Text** with live variables, no code needed: `{zone}`, `{time}`, `{fps}`, `{gold}`, `{currency:<id>}`… and every game icon.
- **Display conditions** without scripts (combat, group, mount, target…) and opacity in combat or under the mouse.
- **Templates**, folders, layouts per specialization, profiles per class or faction.
- **Share** a layout, a folder or a panel with a text string.
- Scripts for advanced users.

## Clients and languages
**Retail 12.x** and **WoW Forever**. English, Français, 简体中文, 繁體中文. Text always uses the font of your client language.

## Migration
Layouts, panels, folders, profiles and custom art of **kgPanels Reloaded** and **kgPanels** are imported automatically; old scripts keep working. The `kgPanels_Reloaded` and `kgPanelsConfig_Reloaded` folders of the package only let nxPanels read your old data: keep them.

## Commands
`/nxp` window · `/nxp edit` edit mode · `/nxp layout <name>` switch layout · `/nxp status` diagnostics · `/nxp help` all commands
